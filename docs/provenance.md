# Exhuma Provenance & Lineage

## Origin & Evolution
Exhuma was created by [Fleect](https://fleect.com/) as a world-class, open-source Universal Component Platform and Registry. It originated from the consolidation of high-performance frontend libraries (`react-toolkit`, `interactive-cards`, `rr6-boilerplate`) into a unified Next.js monorepo architecture.
