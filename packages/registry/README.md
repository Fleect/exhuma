# @fleect/exhuma-registry

Canonical multi-framework component registry schema and compiler for the **Exhuma** Universal Component Platform.

---

## Overview

`@fleect/exhuma-registry` powers the multi-ecosystem component compilation pipeline, providing:

- Canonical component definitions, prop descriptors, and default configurations.
- Native code synthesis for 13 frontend ecosystems (React, Next.js, Vue 3, Svelte 5, Angular 18+, SolidJS, Astro, Laravel Blade, Vanilla JS, WordPress Gutenberg, Web Components, React Native, and Flutter).
- Clean (declarative) and Ejected (zero-dependency standalone engine) generation modes.

---

## Installation

```bash
pnpm add @fleect/exhuma-registry
# or
npm install @fleect/exhuma-registry
```
