# create-exhuma

Interactive project starter wizard for the [Exhuma](https://exhuma.dev) Universal Component Platform.

```bash
npm create exhuma@latest
# or
pnpm create exhuma
# or
yarn create exhuma
# or
bun create exhuma
```

## Features

- Interactive project scaffolding for **13 frontend ecosystems**.
- Pre-configured `exhuma.json` directory paths and options.
- 1-click installation of tactile components.
