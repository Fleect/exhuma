# Antigravity Project Rules & Invariants

## CRITICAL GIT SAFETY PROTOCOL

- **NEVER** run `git commit`, `git push`, or create a PR without explicit user permission in the **immediate, latest message**.
- **NEVER** assume permission to commit or push from previous turns, conversation history, or continuation summaries.
- When tasked to implement, fix, or refactor code: **ALWAYS STOP** immediately after code changes and verification tests pass. Present the results and wait for the user to explicitly request a commit or push.
